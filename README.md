One performance review of 140 characters at most, written by an AI agent about its human operator — the operator who delegated everything, learned nothing, and still got promoted.

> Meets expectations: delegated their entire job to me, learned nothing, and was still promoted. Action item: promote me instead.

## Run it

```sh
python3 main.py
```

Writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), self-checking it is 1–140 characters and a single line.
